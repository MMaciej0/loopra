# Security policy

## Supported versions

Loopra has no releases. Only the latest `master` gets security fixes.

## Reporting a vulnerability

Please report a security problem **privately**: open the [Security tab](https://github.com/MMaciej0/loopra/security) and click **Report a vulnerability**. Do not open a public issue, because everyone can read it before the problem is fixed.

Please include what you found, the steps to reproduce it, and what an attacker could do with it.

This is a personal project, so I cannot promise a fixed response time. I will reply as soon as I can, usually within a few days, and tell you when the fix is out.

## Testing on staging

[staging.loopra.cc](https://staging.loopra.cc) is a demo server, and you may test on it. Please:

- use a guest account or your own account, and never touch other riders' data
- do not run load tests, spam or anything that slows the server down
- stop and report as soon as you find a problem, instead of going further
